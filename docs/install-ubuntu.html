نصب CIWA CRM روی سرور دفتر

روی یک اوبونتوی خام CRM را بالا بیاورید تا بقیهٔ کارمندان از مرورگر خودشان به همان سرور وصل شوند و با حساب اختصاصی وارد شوند. نصب جدا روی سیستم هر کارمند لازم نیست.

۱ تصویر کلی

سه لایه روی سرور اجرا می‌شود. کارمند فقط رابط را در مرورگر باز می‌کند.

هسته + دیتابیس
MariaDB و CRM هسته داخل Docker
:8081
میان‌افزار
ورود و پروکسی امن API
:8787
رابط CIWA
همان صفحهٔ کاری کارمند

مثال: اگر IP سرور 192.168.1.50 باشد، کارمند می‌رود به http://192.168.1.50:8443

۲ آماده‌سازی سرور

با کاربر عادی دارای sudo وارد شوید.

۲.۱ به‌روزرسانی سیستم

terminal
sudo apt update
sudo apt upgrade -y
sudo apt install -y ca-certificates curl git ufw

۲.۲ نصب Docker

terminal
sudo apt install -y docker.io docker-compose-v2
sudo systemctl enable --now docker
sudo usermod -aG docker "$USER"

یک‌بار از نشست خارج شوید و دوباره وارد شوید تا گروه docker اعمال شود. سپس docker compose version را بدون sudo تست کنید.

۲.۳ نصب Node.js 22 و pnpm

terminal
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pnpm@10.34.3
node -v
pnpm -v

۳ آوردن پروژه روی سرور

روش الف) کلون از گیت

terminal
cd ~
git clone <آدرس-ریپوی-شما> crm.ciwa.ir
cd crm.ciwa.ir

روش ب) کپی از کامپیوتر فعلی

پوشهٔ پروژه را با scp یا rsync به سرور بفرستید و داخل همان پوشه بروید:

terminal
cd ~/crm.ciwa.ir

۴ تنظیم فایل .env برای شبکه

terminal
cp env.example .env
nano .env

IP سرور روی شبکهٔ داخلی:

terminal
hostname -I | awk '{print $1}'

نمونهٔ تنظیم با IP فرضی 192.168.1.50 — رمزها را عوض کنید:

.env
CIWA_DB_NAME=ciwa
CIWA_DB_USER=ciwa
CIWA_DB_PASSWORD=یک-رمز-قوی
MARIADB_ROOT_PASSWORD=یک-رمز-قوی-دیگر
CIWA_ADMIN_PASSWORD=رمز-ادمین-اولیه
CIWA_CLIENT_ID=ciwa-integration
CIWA_CLIENT_SECRET=یک-رمز-بلند-تصادفی

CIWA_PUBLIC_URL=http://192.168.1.50:8443
CIWA_CORE_PUBLIC_URL=http://192.168.1.50:8081
CIWA_CORE_URL=http://127.0.0.1:8081
  • به‌جای IP نمونه، IP واقعی سرور را بگذارید.
  • اگر دامنهٔ داخلی دارید، همان را جایگزین کنید.
  • برای HTTP داخل شبکه، CIWA_COOKIE_SECURE را فعال نکنید.
terminal
echo "HOST_UID=$(id -u)" >> .env
echo "HOST_GID=$(id -g)" >> .env

۵ بالا آوردن پایگاه داده و هسته

terminal
cd ~/crm.ciwa.ir
docker compose up -d db crm
terminal
docker compose ps
curl -sI http://127.0.0.1:8081 | head -5

اولین اجرا ممکن است چند دقیقه طول بکشد (Composer و نصب خاموش هسته). اگر خطا بود: docker compose logs -f crm

۶ میان‌افزار و رابط

۶.۱ میان‌افزار

terminal
cd ~/crm.ciwa.ir
set -a
source .env
set +a
node integration/server.mjs

اگر پورت 8787 گوش داد، درست است. با Ctrl+C قطع کنید؛ در مرحله بعد سرویس دائمی می‌سازیم.

terminal
curl -s http://127.0.0.1:8787/api/session

باید شبیه «وارد نشده‌اید» برگردد، نه خطای اتصال.

۶.۲ رابط

terminal
cd ~/crm.ciwa.ir/frontend
pnpm install
pnpm build
pnpm preview --host 0.0.0.0 --port 8443

برای دفتر، preview پایدارتر از pnpm dev است.

۷ سرویس دائمی با systemd

مسیرها و نام کاربر (hossein) را با واقعیت سرور خودتان عوض کنید.

۷.۱ سرویس میان‌افزار

systemd
sudo tee /etc/systemd/system/ciwa-integration.service >/dev/null <<'EOF'
[Unit]
Description=CIWA CRM Integration
After=network.target docker.service
Wants=docker.service

[Service]
Type=simple
User=hossein
WorkingDirectory=/home/hossein/crm.ciwa.ir
EnvironmentFile=/home/hossein/crm.ciwa.ir/.env
Environment=PORT=8787
ExecStart=/usr/bin/node integration/server.mjs
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF

۷.۲ سرویس رابط

systemd
sudo tee /etc/systemd/system/ciwa-frontend.service >/dev/null <<'EOF'
[Unit]
Description=CIWA CRM Frontend
After=network.target ciwa-integration.service
Requires=ciwa-integration.service

[Service]
Type=simple
User=hossein
WorkingDirectory=/home/hossein/crm.ciwa.ir/frontend
Environment=PORT=8443
Environment=CIWA_INTEGRATION_URL=http://127.0.0.1:8787
ExecStart=/usr/bin/pnpm preview --host 0.0.0.0 --port 8443
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF

فعال‌سازی

terminal
sudo systemctl daemon-reload
sudo systemctl enable --now docker
sudo systemctl enable --now ciwa-integration ciwa-frontend
sudo systemctl status ciwa-integration --no-pager
sudo systemctl status ciwa-frontend --no-pager
terminal
cd ~/crm.ciwa.ir
docker compose up -d db crm

۸ باز کردن فایروال

terminal
sudo ufw allow OpenSSH
sudo ufw allow 8443/tcp comment 'CIWA CRM UI'
sudo ufw enable
sudo ufw status

کارمند معمولاً فقط به پورت 8443 نیاز دارد.

۹ ورود اول و ساخت کاربر

  1. از یک سیستم داخل شبکه بروید به http://IP-سرور:8443
  2. با کاربر admin و رمز CIWA_ADMIN_PASSWORD وارد شوید.
  3. از منو به بخش کاربران بروید و برای هر کارمند حساب بسازید.
  4. رمز ادمین را بعد از ورود اول عوض کنید.

هر کارمند فقط همان آدرس را در مرورگر باز می‌کند و با حساب خودش وارد می‌شود. نصب روی سیستم کارمند لازم نیست.

۱۰ چک‌لیست تحویل

وضعیت تیک‌ها در همین مرورگر ذخیره می‌شود.

۱۱ به‌روزرسانی بعدی

terminal
cd ~/crm.ciwa.ir
git pull
docker compose up -d --build db crm
cd frontend && pnpm install && pnpm build
sudo systemctl restart ciwa-integration ciwa-frontend

۱۲ عیب‌یابی سریع

مشکلکار پیشنهادی
از سیستم دیگر صفحه باز نمی‌شودIP سرور، ufw و گوش‌دادن پورت 8443 را چک کنید
صفحه باز است ولی ورود خطا می‌دهدsystemctl status ciwa-integration و لاگ هسته
بعد از ریبوت قطع استdocker compose up -d و start سرویس‌ها
کوکی/نشست عجیب استکارمند باید دقیقاً همان CIWA_PUBLIC_URL را باز کند
pnpm در سرویس پیدا نمی‌شودمسیر کامل which pnpm را در ExecStart بگذارید
logs
journalctl -u ciwa-integration -f
journalctl -u ciwa-frontend -f
docker compose -f ~/crm.ciwa.ir/docker-compose.yml logs -f crm

اختیاری: همه داخل Docker

terminal
cd ~/crm.ciwa.ir
docker compose --profile container up -d
برای کارمند: برو به http://IP-سرور:8443، با کاربری که ادمین برایت ساخته وارد شو.
